Production notes
----------------

The maintainable production source is `harness/`, launched in portable mode by
the root `run.*` scripts with configuration from `config.toml`. The checked-in
Windows Python runtime is an installed production dependency bundle; it is not
a build cache. The `releases/` executables are frozen copies built from the
Python entry points under `scripts/` using PyInstaller. Platform release ZIPs
package the corresponding builds; the Windows setup executable is assembled
from the frozen Windows GUI and CLI by `installer/CrackStack.iss` (Inno Setup).

The checked-in portable Python runtime exists for Windows x64. Linux x64 and
macOS arm64 have frozen release artifacts and ZIP packages, but no bundled
Python interpreter in this tree. Model weights are supplied separately under
`models/`; they are not included in the release source/checksum boundary.
